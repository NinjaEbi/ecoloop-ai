# Limitations

1. A photo cannot confirm internal hardware faults.
2. Functional symptoms are user-reported.
3. AI support depends on verified training data and a model artifact; none is currently installed.
4. Unknown devices use manual fallback.
5. Any later resale estimate is educational and not authoritative market data.
6. Dataset coverage and imbalance must be measured before training.
7. EcoScore is a Phase-1 heuristic, not an LCA.
8. Stakeholders are demo/sample data, not live listings.
9. Professional diagnosis may still be required.
