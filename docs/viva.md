# Viva quick answers

- **Why EcoLoop?** It makes end-of-life decisions more explainable than disposal by default.
- **Why AI?** Where verified data exists, recognition can reduce input effort; uncertainty falls back safely to manual input.
- **Why YOLO/OpenCV?** YOLO is a suitable future detector for labelled device photos; image validation uses practical photo-quality checks. Neither diagnoses internal faults.
- **Black screen?** The user reports power, vibration/sound, charging, display and touch. The system may say “possible display/touch-related issue”, never an IC diagnosis.
- **Unknown device?** It displays unknown and provides manual category/assessment mode.
- **EcoScore?** A transparent 30/25/20/15/10 weighted heuristic stored in configuration.
- **Recommendations?** Five calculated option scores use condition, age, damage and optional economics.
- **Why FastAPI/React/SQLite?** They provide typed APIs, responsive UI, and simple persistent local storage suited to a Phase-1 mini-project.
- **Phase 1 versus future work?** This delivers decision support, not marketplaces, booking, authentication, live listings, hardware diagnostics, or cloud deployment.
